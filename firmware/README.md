## `phone/` (ESP32-S3)

Arduino concatenates every `.ino` file in a sketch folder, so the files here are tabs of **one** program with `phone.ino` as the main file. The folder name matches `phone.ino`, so the sketch opens directly in the Arduino IDE.

| Files | Role |
|---|---|
| `phone.ino` | NyxOS core: UI, boot, networking, base apps, some games |
| `phone_notif_center.ino` | Notifications and Dynamic Island |
| `*_renphone.ino` | One file per feature (gallery, avi, musicbt, remote, chat, call, camera, ina219, about, owner, homeedit, ota_check, wakeword, gamepad, power, doom, nes_*, features, chess, ebook, gutenberg, backup, kamus, emoji, ptr, hwscroll, pager, nyxextras, ppu_engine, and others) |
| `*_core.h`, `backup_crypto.h`, `sec_core.h`, `ryne_engine.h` | Pure C++ logic with no Arduino dependency, so it can be tested on a PC (backup, dictionary, ebook, Gutenberg, RYNE) |
| `rplink.h`, `cam_rx.h`, `cam_avi.h`, `MjpegClass.h` | RPLink protocol, camera frame receiver, AVI writer, MJPEG parser |
| `hw_conf.h`, `display_conf.h` | Hardware and display-variant configuration |
| `i18n.h`, `i18n_dict.h` | UI language engine and generated dictionary |
| `emoji_data.h`, `kamus_data.h` | Built-in emoji sprites and word lists (generated by `tools/`) |
| `extras/chess_smp.cpp` | Second-core chess engine; CI copies it into the sketch's `src/` folder |

**Registering files with CI.** The CI workflow copies a fixed list of files into `build_sketch/`. When you add a new `.ino` or `.h` file, add it to the `cp firmware/phone/... build_sketch/` list in `.github/workflows/build-firmware.yml`, otherwise the build fails at link time.

**Third-party code** (`nofrendo_core`, `esp_doom_core`) lives in [`../third_party/`](../third_party) and is copied into `src/` by CI.

## `cam_bt_coprocessor/` (ESP32-CAM)

A separate sketch, built by the **Build CAM BT Co-Processor** workflow. Its `rplink.h` must be **identical** to `phone/rplink.h`.
