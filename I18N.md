# Dua Bahasa UI / Bilingual UI  (I18N_V1)

**Default: English.** Ganti di **Settings → Language / Bahasa** (bagian DISPLAY/TAMPILAN, di bawah *Font*).
Ketuk barisnya = bolak-balik English ⇄ Indonesia. Pilihan disimpan di NVS (`ui` / `lang`), jadi tetap setelah restart.

## File
| File | Fungsi |
|---|---|
| `i18n.h` | Mesin bahasa: `uiLang`, `RPTR("teks")`, simpan/muat pilihan |
| `i18n_dict.h` | Kamus ID↔EN (**dihasilkan**, jangan diedit tangan) |
| `tools/i18n_pairs.txt` | **Sumber kamus** — satu baris per pasangan: `TEKS_INDONESIA ::: ENGLISH` |
| `tools/gen_i18n.py` | `i18n_pairs.txt` → `i18n_dict.h` |
| `apply_i18n_patch.py` | Membungkus literal UI dgn `RPTR()` + memasang baris Bahasa di Settings (idempoten) |

## Cara kerja
`RPTR("Pengaturan")` mengembalikan `"Settings"` (English) atau `"Pengaturan"` (Indonesia). Teks yang **tidak ada di kamus
dikembalikan apa adanya** (tidak pernah rusak). Teks sumber di kode boleh Indonesia atau Inggris — dua-duanya dicocokkan.
Hasilnya di-cache per alamat literal, jadi murah walau dipanggil tiap frame. Cache gambar Home / Control Center
otomatis dibuang saat bahasa diganti.

## Menambah / memperbaiki terjemahan
1. Tambah baris di `tools/i18n_pairs.txt` (teks harus **sama persis** dengan literal di kode, spasi ujung ikut dihitung).
2. `python3 tools/gen_i18n.py`
3. `python3 apply_i18n_patch.py`  (membungkus literal baru yang sudah ada di kamus; aman diulang)
4. Commit `i18n_dict.h` + file `.ino` yang berubah.

Teks baru yang kamu tulis sendiri di kode: cukup tulis `RPTR("teks")` langsung (di dalam fungsi, bukan di inisialisasi global/`static`).
Teks dinamis (buffer yang isinya berubah): `RPTRD(buf)` (tanpa cache).

## Yang BELUM diterjemahkan (dibiarkan apa adanya)
- Teks hasil rakitan `String + angka` / `snprintf` yang format-nya belum ada di kamus.
- Log serial `[...]`, isi file config, protokol SIP, prompt ke Gemini.
- Halaman web Remote (`RC_PAGE`) dan Gamepad (`PAD_PAGE`) — HTML/JS sendiri.
- Data kamus `kamus_data.h`, daftar soal Trivia, isi buku.
Kalau ada teks yang masih Indonesia di mode English, tambahkan ke kamus (langkah di atas).
