# SD card configuration

Most settings can be set in the app, but the on-screen keyboard is slow, so many of them can also be provided as plain-text files on the SD card.

- [File layout](#file-layout)
- [Configuration files](#configuration-files)
- [Examples](#examples)
- [Web File Manager](#web-file-manager)

## File layout

```
/
├── gemini_key.txt   nasa_key.txt   wallpaper.jpg   emoji.bin
├── chat.cfg         sip.cfg        turn.cfg        chess.cfg
├── ai_memory.txt    ryne2.bin      notepad.txt     kamus.txt
├── music/   memo/   screenshot/   update/   Kamera/   .thumbs/
├── backup/   books/
├── *.avi   *.mjpeg   *.nes        doom1.wad   (provided by you)
└── (Gallery album folders)
```

## Configuration files

| File | Used by | Format and notes |
|---|---|---|
| `/gemini_key.txt` | AI Chat and dictation | Contains the API key. If the SD card is not detected, the key is stored in NVS. |
| `/nasa_key.txt` | NEO, EPIC, NASA Gallery | `DEMO_KEY` can be used, but its limit is small. The Astronomy app does not need a key. |
| `/chat.cfg` | Chat | `host=`, `user=`, `pass=`, `name=` |
| `/sip.cfg` | Phone (SIP) | `host=`, `user=`, `pass=`, `name=`, and optionally `transport=tcp` or `transport=udp` (default `tcp`). |
| `/turn.cfg` | Phone (TURN relay) | `host=`, `port=` (default 3478), `user=`, `pass=` |
| `wallpaper.jpg` | Home and Lock Screen | The file name must be exactly `wallpaper.jpg`. |
| `/emoji.bin` | Emoji (all text and the keyboard) | Optional. Generated by `tools/make_emoji_bin.py` from Noto Emoji or Twemoji. Without it, the built-in set of 54 sprites is used. See [System UI](./features/system-ui.md#emoji-beta). |
| `/chess.cfg` | Chess (online) | `host=`, `user=`, `pass=`. Optional; the broker can also be set in the app. Separate from `chat.cfg`. |
| `/kamus.txt` | Keyboard dictionary | Optional. One word per line, most frequent first (the `word 1234` format is also accepted), 2 MB maximum. See [System UI](./features/system-ui.md#keyboard-dictionary-word-suggestions-and-autocorrect-beta). |
| `/backup/nyx_NNN.nbk` | Backup & Restore | Created automatically (at most 6 files). Not encrypted unless password encryption is on. See [System tools](./features/system-tools.md#settings-backup-and-restore-beta). |

## Examples

**`chat.cfg`**

```
host=xxxxxxxx.ala.eu-central-1.emqxsl.com
user=yourusername
pass=yourpassword
name=Ren
```

**`sip.cfg`**

```
host=sip2sip.info
user=username
pass=password
name=Ren
transport=tcp
```

**`turn.cfg`**

```
host=free.expressturn.com
port=3478
user=USERNAME
pass=PASSWORD
```

## Web File Manager

While WiFi is on, open `http://<device-ip>/` to upload, edit, download and delete files, set the Gemini key and change the wallpaper. See the security note in [Security](./security.md).
